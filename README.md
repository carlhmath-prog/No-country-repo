# Plataforma GovTech - Automatización de Propuestas Técnicas

## Descripción

Plataforma SaaS orientada a contrataciones públicas en Perú que busca automatizar la preparación y revisión de propuestas técnicas y económicas.

## Objetivos

- Reducir errores en propuestas para procesos de selección.
- Automatizar validaciones contra bases y TDR.
- Facilitar la revisión por entidades evaluadoras.

## Módulos

### Módulo Postulante
- Armado de propuesta técnica.
- Validación de requisitos.
- Generación automática de formatos.

### Módulo Evaluador
- Revisión automática de ofertas.
- Motor de reglas.
- Alertas de incumplimientos.

## Stack propuesto

- PostgreSQL

Frontend:
- React + TypeScript
